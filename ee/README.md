## 📖 Overview

HostMK-Security-Framework follows an **Open Core** model.

The repository contains two distinct editions:

| Edition | Location | License |
|----------|----------|----------|
| Community Edition | `/core` | Apache 2.0 |
| Enterprise Edition | `/ee` | Commercial Proprietary License |

The Community Edition provides all essential security building blocks.

The Enterprise Edition provides advanced capabilities designed for:

- 🏢 Enterprises
- ☁️ SaaS Providers
- 🛡 Security Teams
- 🏦 Financial Platforms
- 🏥 Healthcare Platforms
- 🏛 Government Systems
- 🌍 Large Multi-Tenant Applications
